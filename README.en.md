## About

This is Lingem's personal blog. Here I document my HomeLab adventures, share my love for ACGN, and keep notes on my Japanese learning journey.

I'm not aiming to be a tech influencer — I just write down the pitfalls I've stumbled into and the things I've learned, both as a reference for my future self and hopefully to help others on a similar path.

### Topics

- 🖥️ **HomeLab** — NAS, Docker, self-hosted services
- 🎬 **ACGN** — Anime reviews, manga recommendations, gaming thoughts
- 🇯🇵 **Japanese Learning** — Study notes and resources
- 📦 **Open Source Tinkering** — Small tools and scripts from my experiments

---

## Features

Built on the [Firefly](https://github.com/CuteLeaf/Firefly) theme:

- **Astro + Tailwind CSS** — Modern tech stack with fast load times and great SEO
- **i18n** — Multilingual UI (zh-CN, zh-TW, en, ja, ko, ru)
- **Full-text Search** — Client-side search via Pagefind
- **Responsive Design** — Optimized for desktop, tablet, and mobile
- **Swup Page Transitions** — Smooth SPA-like navigation
- **4 Wallpaper Modes** — Banner, fullscreen, transparent, solid color
- **Flexible Sidebar** — Single or dual sidebar layouts
- **Post Layouts** — List / Grid / Masonry
- **Light/Dark Mode** — Light, dark, or follow system
- **Markdown Extensions** — Mermaid, PlantUML, KaTeX, GitHub cards, Wiki Links
- **Dynamic / Memos** — Native microblog or Memos integration
- **Bangumi** — Anime, book, music, game collection showcase

## Local Development

### Prerequisites

- Node.js ≥ 22
- pnpm ≥ 9

```bash
git clone https://github.com/engpago413/Lingem.git
cd Lingem
pnpm install
pnpm dev
```

The dev server starts at `http://localhost:4321`.
