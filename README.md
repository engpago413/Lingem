## 关于本站

这里是 Lingem 的个人博客。主要记录 HomeLab 折腾经验、ACGN 相关内容，以及自学日语的点滴。

我不追求成为什么技术博主，只是把自己踩过的坑、学到的东西写下来。一方面方便自己以后回顾，另一方面也许能帮到和我一样在摸索的人。

### 内容方向

- 🖥️ **HomeLab** — NAS、Docker、自托管服务折腾记录
- 🎬 **ACGN** — 追番笔记、漫画推荐、游戏心得
- 🇯🇵 **日语学习** — 自学路上的方法与资源
- 📦 **开源折腾** — 折腾过程中的小工具与脚本
